# GNews API

## Overview

Search through millions of articles from over 80,000 large and small news sources and blogs using the GNews API. This plugin allows you to search for articles by keywords and browse top headlines by category and country, then open them directly in your browser.

The plugin uses the GNews API service to fetch real-time news articles. You need a free API key from [gnews.io](https://gnews.io) to use this plugin.

## Features

- **Keyword Search**: Search for articles using specific keywords or phrases
- **Top Headlines**: Browse top headlines by category (Business, Technology, Sports, etc.)
- **Country Filtering**: Filter news by country (US, UK, Canada, Germany, France, etc.)
- **Language Support**: Support for multiple languages (English, Spanish, French, German, etc.)
- **Advanced Settings**: Sort by publication date or relevance
- **Display Options**: Choose what to display (title, description, content)
- **Direct Access**: Click any article to open it in a new browser tab

## How to use

1. **Get API Key**: Register at [gnews.io](https://gnews.io) and get your free API key
2. **Install Plugin**: Open the plugin from the Plugins tab in ONLYOFFICE
3. **Setup**: Enter your API key when prompted
4. **Search**: Use the Search tab to find articles by keywords
5. **Headlines**: Use the Top Headlines tab to browse news by category
6. **Open Articles**: Click on any article to open it in your browser

### Search Tab

1. Enter keywords in the search field
2. Choose what to display using the checkboxes (Title, Description, Content)
3. Optionally configure advanced settings (language, sort order)
4. Click "Find" to search

### Top Headlines Tab

1. Optionally enter keywords to filter headlines
2. Select a category (General, Business, Technology, etc.)
3. Select a country
4. Click "Find" to get headlines
